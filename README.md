# Atelier 02 — Mini-projet Web à organiser

Ce dépôt contient un petit site HTML/CSS/JavaScript. **Les fichiers sont volontairement tous placés à la racine.** Au départ, le site fonctionne ainsi.

## Votre mission

1. Clonez **votre propre copie** du dépôt dans VS Code (instructions données en classe).
2. Ouvrez `index.html` avec Live Server et testez le bouton « Afficher le message ».
3. Dans le terminal PowerShell, créez les dossiers `assets/css` et `assets/js`.
4. Déplacez `style.css` dans `assets/css` et `script.js` dans `assets/js`.
5. Rechargez le site : qu'est-ce qui ne fonctionne plus ? **Corrigez les deux chemins dans `index.html`** puis retestez.
6. Transformez ce README en fiche de présentation de **votre** projet : description, technologies, arborescence, lancement et auteur.
7. Personnalisez le site (titre, texte, couleurs ou nouvelle matière).

## Arborescence attendue

```text
mon-projet/
├── index.html
├── README.md
└── assets/
    ├── css/
    │   └── style.css
    └── js/
        └── script.js
```

## Gardez plusieurs versions Git

Faites au moins trois **nouveaux commits** au fil des modifications, par exemple :

- `refactor: organise CSS and JS folders`
- `docs: complete project README`
- `style: personalise student website`

Pour chaque version : `git status` → `git add .` → `git commit -m "message précis"` → `git push`.

**À vérifier :** le site s'affiche correctement, le bouton fonctionne, et vos commits apparaissent sur **votre dépôt GitHub**.
